# srisrithakur.com

Independent, non-commercial home for the devotees of Sri Sri Thakur Anukulchandra.
Not affiliated with Satsang, Deoghar or any Satsang Vihar.

Static site deployed on Cloudflare Pages. Every push to `main` goes live.
Routes (/teachings, /life, /library, /map, /contribute, /about, /daily-wisdom, /events, /languages, /contact) are served by `index.html`.

## Prayer pages in five languages

`/satsang-morning-prayer-{english,hindi,odia,bengali,assamese}` and the same for
`/satsang-evening-prayer-…` are generated by `node tools/build-prayer-pages.mjs`
(a GitHub Action reruns it on every push to `data/prayers/` or `tools/prayers/`).
Do not edit those HTML files by hand.

Prayer text lives in `data/prayers/lyrics/<page>/<prayer>.<language>.txt`, one line per
line and a blank line between stanzas. It is printed exactly as written. Optional first
line: `# source: https://…` (shown under the prayer). For each language page:

1. `<prayer>.<language>.txt` (hindi, bengali, odia, assamese) is used if present.
2. Otherwise the Bengali, Odia and Assamese pages convert `<prayer>.hindi.txt` letter by
   letter into their script (`tools/prayers/script-convert.mjs`).
3. Otherwise the English-letters text (`<prayer>.latin.txt`) is shown.

Page copy (headings, labels, FAQ) for each language is in `tools/prayers/i18n.mjs`.
